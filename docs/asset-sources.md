# 素材来源与维护

本项目的角色、地名和列车故事为虚构。运行时资源位于 `src/assets/`，其明确路径、尺寸、保护哈希在 `scripts/asset-manifest.json`。

- 人物、照片与场景由项目内像素绘制源、经项目所有者确认的内置图像生成候选和本地处理/合成构成；未使用网络占位图，不宣称全部为手工逐像素画稿。
- `art/character-style-reference/ivy-80.png` 为已确认、不可覆盖的 Ivy 80×80 / 48 色基准，7 倍预览仅用于查看。
- `art/morrow-selfie/` 为已批准的 A / LIGHT 正式母版及检查输入。恢复脚本只复制已确认的结局文件，不重画人物。
- `art/curated/` 是选定的正式素材副本，基础生成器采用这些副本保持已经确认的画面。
- Fusion Pixel zh-Hans 字体：SIL Open Font License 1.1，原文 `docs/licenses/fusion-pixel-ofl.txt`。
- Google Noto Emoji SVG：Apache License 2.0，原文 `docs/licenses/noto-emoji-apache.txt`。
- 环境音、车轮、系统音和背景声由 Web Audio 本地合成。中文到站广播是本机 Tingting 系统语音生成的本地 WAV，包含相应字幕。

原创代码、剧情与图像未另行指定开源许可证。第三方字体和 Emoji 按各自许可使用。开发审核、旧候选、玩家诊断资料、整包备份和测试产物不包含在公开发布快照中。
